# Research

Область воспроизводимых исследовательских и экспериментальных материалов. Сырые логи, реальные секреты и результаты локальных запусков в Git не хранятся.

- `datasets/` — версии корпусов данных без секретов и персональных данных;
- `scenarios/` — контролируемые сценарии атак и проверки;
- `experiments/` — конфигурации и результаты экспериментов;
- `tools/` — исследовательские инструменты.
