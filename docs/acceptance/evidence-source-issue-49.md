## Acceptance criteria

Формулировки из #49; отметки относятся к локальной приёмке:

- [x] Evidence показывает ссылку и допустимый фрагмент; сырой журнал открывается только из карточки конкретного события и отображается как инертный текст, без выполнения HTML или сценариев.
- [x] Право чтения сырого журнала соответствует ролям SecOps, DevOps и Auditor; первая учётная запись — SecOps. Ответы с сырым журналом и Evidence запрещают браузерное кэширование.
- [x] После удаления источника карточка явно показывает «источник удалён», не выдавая недействующую ссылку за доступную.

| Область | Наблюдаемое доказательство |
| --- | --- |
| Источник | Нормализатор связывает запись с сенсором, поколением и байтовым смещением; reader отдаёт одну исходную JSON-строку через TLS. Core получает её по Evidence конкретной задачи, без переданного браузером пути или URL. |
| Интерфейс | Фрагмент до 512 Unicode-символов, отметка сокращения, раскрытие исходника внутри карточки. HTML экранируется, raw response имеет text/plain; JavaScript вставляет его через textContent. В браузере проверены script и img/onerror: элементы из них не создаются. |
| Доступ | HTTP-тесты допускают SecOps/DevOps/Auditor и запрещают Developer/Service Principal/неизвестную роль. Штатный вход — один SecOps; роль сохраняется сервером в сеансе, запросом не подменяется. |
| Сеанс и кэш | Без сеанса, с подделанным/истёкшим сеансом или одним токеном сборщика — 401; неподходящая роль — 403. Успех и ошибки 401/403/404/410/503 имеют no-store. Явный просмотр продлевает idle timeout, poll=1 не продлевает. |
| Удаление | После удаления известного файла — 410, отметка удаления, отсутствие ссылки и фрагмента; command.text в проекции карточки/API — null. Анализ и аудит задачи сохраняются. Подтверждение удаления хранится без текста и переживает недоступность reader. |
| Неопределённость | Недоступные reader/реестр/каталог, подмена, symlink, неизвестное поколение и возможный gzip-архив не считаются доказательством удаления. Временный сбой может восстановиться; ротация сохраняет доступ по идентичности файла. |

Полный runtime запускается с `CORE_GUARD_MODEL_DIR`,
`AI_SENTINEL_REQUIRE_GUARD=1` и `AI_SENTINEL_RUNTIME_REUSE_IMAGES=1` после явной
сборки всех локальных runtime-образов из этого рабочего дерева. Реальная модель
закреплена прежним ADR 0005; алгоритм и порог не изменялись.

Десятисервисный вариант с collector, reader и Guard поднялся healthy. Настоящая
Telnet-команда `echo "<script>alert(49)</script>"` прошла Cowrie → нормализатор →
Fluent Bit → TLS → Core → API/карточку. Raw URL вернул ровно одну исходную строку.
Отдельная запись входа по raw URL содержит синтетический пароль, а нормализованное
событие, карточка и фрагмент Evidence его не содержат.

Проверены отказ TLS без доверенной CA и при неверном DNS-имени сертификата,
отказ reader без его отдельного токена и с токеном collector, read-only обоих
mounts reader, отсутствие его host-портов/Docker socket и membership только в
core_management. Из Cowrie и Target App reader недостижим по DNS и прямому IP;
Core/collector/reader не достигли внешнего адреса и опубликованной страницы
через host.docker.internal. Прежняя приёмка Phase 1 также прошла.

Остановка reader даёт временную недоступность без отметки удаления; после
запуска тот же raw URL снова работает. Ротация сохраняет доступ. После удаления
raw URL возвращает 410, метаданные показывают deleted и не выдают текст/ссылку.
Анализ и аудит совпадают с исходными. Подтверждение удаления сохраняется после
пересоздания Core, остановки reader, полного down без -v и нового up,
отключения evidence overlay с --remove-orphans и его повторного включения.
Прежний восьмисервисный вариант Core без collector/reader также прошёл.

Приёмка использует собственные случайно названные Compose projects, временные
CA/credentials и named volumes. Рабочие пользовательские контейнеры и тома
не затрагиваются. После полного прогона его контейнеры и тома удалены.
Исходные три незакоммиченных файла сохранены без изменений.

уязвимом Target App остаются прежними; отдельный полный скан Core — 0 findings.

## Ограничения

Автоматическая физическая очистка всех копий через 14/30 дней остаётся #51.
Скрытие текста после подтверждённого удаления источника не означает стирание
сохранённого события из SQLite. Gzip-архивы этим reader не распаковываются;
неопределённость не подменяется утверждением об удалении. Для второго человека
потребуется отдельная учётная запись; общий пароль не распространяется.
Прямой HTTP страницы остаётся ранее принятым ограничением лабораторной версии.
