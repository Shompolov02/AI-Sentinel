# Packages

Область переиспользуемых версионируемых Python-пакетов. Общий код публикуется через явный workspace-пакет; скрытые связи между сервисами не допускаются.

- `common/` — будущие нейтральные общие утилиты;
- `contracts/` — зарезервированная область для согласованных контрактов после отдельного решения.
- `smoke/` — минимальный установленный пакет для проверки workspace и packaging.

Конкретная JSON-схема События безопасности на этом этапе намеренно не определена.
