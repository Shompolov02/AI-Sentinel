# Services

Область будущих самостоятельно разворачиваемых сервисов. Каждый сервис должен иметь явные зависимости и не импортировать исходный код другого сервиса напрямую.

Подкаталоги фиксируют границы будущих компонентов, но пока не содержат бизнес-логики или сетевых контрактов:

- `api-gateway/` — защищённый входной контур;
- `ai-agent-core/` — когнитивное ядро и триаж;
- `honeynet/` — изолированный ложный периметр;
- `target-app/` — преднамеренно уязвимый Target Web Application для стенда;
- `telemetry/` — сбор и нормализация телеметрии.
